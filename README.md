# Sport Matches

Адаптивная страница для просмотра спортивных матчей, коэффициентов и статистики команд.

![Логотип проекта](img/logo.png)

## Возможности

- просмотр и раскрытие карточек матчей;
- фильтры «Избранное» и «Не просмотренные»;
- адаптивная вёрстка и мобильное меню.

## Технологии

- HTML
- CSS
- JavaScript

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

Проект доступен по адресу `http://localhost:8000`.
